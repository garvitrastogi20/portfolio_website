# Minimalist Creative Portfolio Website

A premium, high-end creative portfolio website engineering my journey, software development stacks, and algorithmic problem-solving milestones. Rebuilt with an ultra-clean layout design, responsive geometry, and fluid micro-interactions.

🚀 **Live Link:** https://garvitrastogiportfolio.netlify.app/

---

## 📐 Design & Visual Features

* **Creative Coding Aesthetic:** Set against a deep terminal midnight-blue canvas with a custom tracking digital blueprint grid overlay.
* **Silky Fluid Cursor:** Integrated a custom, hardware-accelerated motion-interpolated cursor ring that morphs effortlessly into a bright tracking dot when interacting with clickable elements.
* **Premium Typography:** Clean pairing of *Syne* for expressive, geometric headers and *Inter* for highly scannable, razor-sharp body text.
* **Asymmetric Layout:** Optimized grid systems with sleek surface cards and deep visual depth transitions that react dynamically on hover.
* **Performance First:** Built using clean, pure HTML5, CSS3 variable architectures, and vanilla JavaScript for lightning-fast loading speeds and zero build overhead.
